## 🌿 Sobre o Projeto
Este projeto faz parte do componente extensionista da disciplina[cite: 13]. [cite_start]Trata-se de uma API RESTful desenvolvida com **NestJS** para registrar e consultar ações sustentáveis, promovendo a conscientização alinhada aos **ODS 12** (Consumo e Produção Responsáveis) e **ODS 13** (Ação Contra a Mudança Global do Clima).

## 🚀 Funcionalidades Obrigatórias
* **POST /pratica**: Permite o cadastro de ações como uso de copos reutilizáveis ou transporte não poluente[cite: 31, 35].
* **GET /historico**: Retorna a lista completa de práticas cadastradas para consulta[cite: 38].
* **GET /estatisticas**: Exibe um resumo consolidado com totais de práticas e usuários mais ativos[cite: 44, 47, 49].

## 🛠️ Tecnologias
* NestJS
* MongoDB (Configuração estruturada no código)
